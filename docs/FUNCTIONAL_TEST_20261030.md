## 本次发现并修复

原来“请把编号 … 的衣服名称改为 …”没有开放修改预览工具，真实模型只能回复，无法生成待确认操作。原因是明确写入意图词表缺少“改为、改名、重命名”。

补齐常用表达，仍保留原有提问、否定、引用、假设和历史陈述过滤。增加正反向回归，重新验证真实模型生成待确认快照。任何表达都不等于最终确认，原有 PendingAction 和库存快照校验继续生效。

此前的 GitHub CI 曾发现默认向量后端依赖缺失，现已统一使用项目提供的 SQLite 向量后端，并保留显式选择 Chroma 的能力。新增不允许导入 Chroma 的持久化检索回归，防止问题被本机额外安装的包掩盖。项目现仅维护 Windows 客户端和 Windows CI。
