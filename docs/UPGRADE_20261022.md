# StyleMate 业务与桌面升级记录

## 已交付

1. 新增多标签 Skill 路由，按任务合并只读工具；未明确增删改时不开放写提案工具，执行节点再次检查权限。PendingAction 与归属／快照／TTL 校验保留。
2. 知识检索增加原查询保留和有限术语扩展；构建候选前再次过滤用户、会话范围，记录只含数量的审计结果。
3. 增加连衣裙完整搭配路径，继续执行季节、温度、鞋履、外套及排除规则。修改衣物属性会使搭配缓存失效。
4. 当前机器 Chroma Rust 及 HNSW 写入发生原生崩溃，不能用 Python try/except 捕获。增加标准库 SQLite 精确向量后端，Windows 默认使用它；Chroma 仍可选，旧向量文件不覆盖。此后端适合个人小语料，不宣称 ANN 性能。
5. 增加桌面对话工作区，保留衣橱工作台与历史对话。新增 Start.cmd、原生窗口启动器、独立 Python 便携包、打包脚本及依赖锁定清单。

## 验证

完整核心与 UI 测试已覆盖 217 项；新增测试包含模型越权工具请求、复合任务路由、连衣裙约束、术语召回、便携向量持久化／过滤／无效向量、桌面对话和工作台切换。

内置 128 件衣物本机实测，无温度条件的搭配生成约从 8.7 秒降至 0.9 秒。通过提前应用硬约束、折叠评分等价的鞋履／外套候选，以及只构建更优组合的输出对象减少重复计算。无温度、8°C、28°C 三种条件与优化前结果逐字段一致；该耗时仅是当前机器的演示库结果。

2026-10-22 重跑固定 Hash Embedding 评测：101 个用例，其中 60 个检索用例、20 个图执行用例。Recall@5 95.00%，MRR@5 98.06%，工具路径、参数契约、确认写入与循环上限检查均为 100%。本轮固定集的召回指标与旧结果相同，不能写成已提高，也不能代表真实模型或用户效果。

新报告为 artifacts/agent_evaluation_20261022.json；旧报告保留。界面历史指标仍标为固定离线回归集结果。

独立解压目录用自带 Python 打开对话界面并完成洗护快捷流程；WebView2 隐藏窗口创建／关闭测试通过。首次完整分发不带开发者数据库、图片上传、.env 或 API Key。

## 下一阶段的验收目标

- 收集自然表达、困难负例及多文档问题，使用真实 Embedding 做独立检索评测。
- 对原图与实物衣物进行相似检索，比较视觉模型和人工标注的检索结果。
- 将已有反馈记录接入排序，区分不喜欢原因、近期穿着及长期偏好，并提供撤销。
- 继续在不同库存规模测量耗时与多样性，保留等价剪枝的结果一致性回归。
- 完善原生窗口的进度、取消和设置体验。当前桌面版复用 Streamlit 业务界面，尚未完全重写为独立前端。
