# RAG 全链路检查与知识覆盖评估

日期：2026-10-31。默认语料保持原版本，避免把扩库效果混入检索实现的前后对照。

## 结论

现有 RAG 可以支撑已覆盖的基础问答，但不足以支撑“全面材质洗护、完整场景着装知识”的产品承诺。衣橱管理、库存搭配、天气 API 和确定性规则并不全部依赖 RAG，知识不足不等于这些功能不能运行。

最明确的问题有三类：长文档命中后证据丢失、未知问题返回无关片段、知识覆盖偏窄。本轮修复长文档证据丢失、向量候选过滤顺序，以及抽样暴露的材质、尺寸与引用边界；泛化误召回仍是未解决项，知识扩充按独立语料版本推进。

## 链路与切分

```text
内置已审核摘要 / 所属会话上传文档
  → 页与章节切分 → 查询扩展与适用范围过滤
  → BM25 + 可选 Embedding → RRF 排名融合
  → 每文档片段配额与去重 → 查询相关摘录
  → KnowledgeQASkill 来源格式和有限范围检查
  → 模型上下文 / 确定性展示 → 引用
```

| 环节 | 实际行为及检查结论 |
| --- | --- |
| 内置切分 | 已由维护者整理成原子摘要；41 条已发布记录长 46–95 字，中位数 58 字，通常无需再次按固定长度切碎 |
| 上传文档 | TXT/Markdown/PDF 文本，600 字符一块、80 字符重叠；按页与章节组织；这是字符预算，不是 token 预算 |
| 章节 | 原解析依赖空行，连续 Markdown 标题会被并入前一节；现改为逐行识别标题并保留章节边界 |
| 检索 | 中文单字及双字组合 + 英文词 BM25，标题加权；原查询和有限别名扩展各自排名，再与向量分支融合 |
| 过滤 | 内置知识按有限材质/问题范围过滤；用户资料仍按 owner、conversation 隔离；过滤不是完整语义支持性判断 |
| 向量 | 默认 SQLite 精确距离排序；可选 Chroma。修复为在 Top K 前应用可用证据键与会话过滤，避免无关近邻占满名额后被丢弃 |
| 融合 | RRF 常数 60，召回池为请求数量的 3 倍。当前没有训练式或 Cross-Encoder 相关性重排器 |
| 摘录 | 原先只按问题前两个字符定位并截取 180 字；现选择覆盖查询词且保留后续说明的最多 360 字窗口，短摘要完整保留 |
| 文档去重 | 原先每个文档最多一段，跨页/章节问题只能拿到一半证据；现最多保留两段互补片段，并抑制近重复片段 |
| 组装 | Skill 不再把新摘录再次截成 240 字，使用最多 400 字的有界数据；确定性展示可保留同一用户文档的两段及位置，引用链接去重 |
| 验证 | 来源 URL 格式、适用范围检查和最多一次检索改写；不等同于逐句证明答案由证据支持 |
| 材质边界 | 夹克、衬衫、外套等品类不代表已知材质，未知成分先追问标签，不直接套用羊毛或 GORE-TEX；英文类别兼容中英混排 |
| 精确尺寸 | 内置尺寸条目仅解释测量概念，询问某款具体尺寸时返回需要产品尺码表，不以一般胸宽说明冒充该款数据 |
| 模型引用 | 服务最终展示只挂载回复中明确出现的登记来源 URL，并去重；不再把所有检索候选自动当作回答引用。这是显式 URL 校验，不是引用蕴含性验证 |

600/80 在当前合成边界样本中未丢失标注短语，主要故障发生在检索后截断和文档去重，而非切块尺寸本身。因此没有仅凭经验把 chunk size 随意调大或调小。PDF 表格、扫描件 OCR、跨页表头继承和真实混合版式仍缺乏专门验收；扫描 PDF 可能没有可提取文字。

RRF 返回的归一化分数是排名信号，不能解释成相关概率、回答置信度或绝对拒答阈值。

## 固定检索题测量

沿用 40 条检索题（28 条有答案、12 条无答案），保留原问题和标签。使用本机配置的真实 Embedding，前后核对题集与语料指纹相同。

| 方法 | Recall@5 | Hit@1 | MRR@5 | NDCG@5 | 12 条无答案拒检 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BM25 | 96.43% | 85.71% | 0.9107 | 0.9190 | 11/12 |
| 真实向量 | 96.43% | 82.14% | 0.8810 | 0.8978 | 11/12 |
| 真实混合 | 96.43% | 89.29% | 0.9286 | 0.9379 | 11/12 |

上述指标在本轮前后相同。混合检索在此样本中改善排序，没有提高相对于 BM25 的 Recall。不能把此前原 20 条有答案题的 95% 与当前 28 条有答案题的 96.43% 直接写成优化增幅。

Precision@5 约 22.14%。许多问题只标注一个或少量相关记录，因此不能把其余所有返回内容直接判为错误；需要更完整的人工相关性标注后，再评价精排与上下文噪声。

离线 Hash 向量只是可重复测试替身，扩展集上的混合 Recall@5 为 94.64%，低于 BM25 的 96.43%，不能代替真实 Embedding 质量结论。

## 新诊断样本与改动收益

新增题在本轮修复前冻结：8 个已有证据问题、12 个候选覆盖需求、6 个域外/具体信息不足问题，以及 6 个合成长文档。由项目开发者编写，不是独立人工盲测。

| 长文档阶段：按每个文档的标注短语覆盖比例求平均 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 标注短语保留在切块中 | 100% | 100% |
| 标注短语保留在检索摘录中 | 50% | 100% |
| 标注短语保留在 Skill 上下文中 | 50% | 100% |

无 Embedding 和真实 Embedding 两条路径均复测。六个文档只有九条有限标注短语，100% 不是自然文档检索准确率，更不是生成答案准确率。新增回归测试还验证：连续标题、跨页互补证据、边界重叠、未越过用户/会话边界、展示引用不混入其他文档，以及 24 个不适用近邻不能挤掉唯一适用候选。

8 个已覆盖诊断问题 Recall@5 为 100%。但新的 6 个域外或具体信息不足问题中，5 个仍会返回一些片段。例如税务问题能召回旅行资料，未知品牌精确尺码能召回通用尺寸说明。**返回相关领域背景不代表已经回答具体问题；检索层返回了片段也不等于模型一定会编造答案。** 新增问题暴露的泛化拒答缺陷没有通过逐条追加题目中的税务、租赁等词语掩盖。

后续应先标注“直接支持、仅背景、无关、冲突”的候选相关性，再校准拒答与精排；对精确品牌型号、未知纤维、混纺和多条件问题，不能只凭词面重合判断可以回答。

## 知识库是否足够

| 记录类型 | 数量 | 能否进入默认事实检索 |
| --- | ---: | --- |
| 已审核来源摘要 | 41 | 是 |
| 待审核摘要 | 24 | 否 |
| 项目经验规则 | 21 | 否，业务工具可按规则使用并标明性质 |
| 合计 | 86 | 不应把 86 当作有效事实知识量 |

已发布九类主题数量为：fabric 5、care 11、storage 4、wardrobe 2、size 3、weather 5、scenario 7、style 1、color 3。主题标签齐全不代表每类覆盖充分。

现有已发布材质相关证据集中于羊毛与 GORE-TEX。棉、真丝、亚麻、羊绒、羽绒、皮革、涤纶、尼龙和粘胶没有对应的明确材质摘要。该结论基于当前记录与有限材质表达审计，不是对所有可能知识点的穷尽证明。

候选覆盖需求中的混纺、分污渍处理、鞋履、礼仪着装等问题虽然可能召回普通洗标或面试资料，但这些资料不足以支持具体处理方法。12 个候选需求也不是全部已经承诺的功能：航空携带限制属于需实时核对的外部规则，应另行界定产品范围，不能把历史离线知识当作当前规定。

## 是否需要抓取更多知识

**需要定向补充与审核，不需要无目标批量抓取。** 建议顺序：

1. 先审查 24 条待审核记录，并与现有分层、天气等已发布内容归并，避免以重复摘要充数。
2. 优先补齐常见材质的洗标判断、洗涤、干燥/熨烫、收纳、禁忌与适用限制；不能把一个品牌的机洗许可推广到整个材质。
3. 再补充鞋履、具体污渍、混纺和场景 dress code。审美搭配经验继续标为项目规则或带场景的建议，不包装成普适权威结论。
4. 保留来源白名单、章节定位、审核日期、适用产品/材质、限制、摘要哈希和版本；维护时先比对来源变更，再重新审核，不自动发布新抓取正文。

已逐段阅读并比较三个可补充来源：[ARKET 真丝指南](https://www.arket.com/en-ww/editorial/silk-care-guide/)、[REI 羽绒服指南](https://www.rei.com/learn/expert-advice/how-to-wash-down-jacket.html)、[UNIQLO 亚麻衬衫指南](https://www.uniqlo.com/au/en/news/topics/2021101801/)。候选事实及具体限制见[补充来源计划](../../data/knowledge/proposals/20261031-source-plan.json)。这些是按品牌/产品范围整理的候选，不因抓取成功就成为默认可用事实。

扩充默认语料时要另建知识与评测版本。现有测试把真丝、羽绒等部分问题标成“当前无证据”；扩库后应更新新版本标签，并保留旧语料、旧题目和原始报告作历史对照。本轮保持默认语料不变，从而能够隔离验证检索实现改动。

## 来源可维护性

23 个登记 URL 各做一次有超时和大小上限的访问：12 个 HTTP 2xx、7 个 403、3 个读取超时、1 个 404。403 和超时可能来自反爬、网络及限流，不能据此判定事实错误或永久下线；FTC 链接本次为 404，需要优先复核或寻找保留相同依据的官方新地址。

这只是传输可访问性检查，未宣称实时核验全部 41 条摘要的语义。没有将抓取的网页/PDF 全文写入仓库；只保留状态、最终 URL、有限响应的哈希和检查时间。

## 完整问答抽样与发布验证

另对 8 个公开合成问题单次检查服务到回复的完整路径，使用同一对话模型及 900 token 输出预算，其中 5 条经过确定性业务分支、3 条经过模型图；不把它们称为 8 条纯模型任务或人工盲测。

- 原先未知纤维夹克问题被返回 GORE-TEX 护理摘要；修复后追问材质/洗标，并不附 GORE-TEX 引用。
- 具体虚构品牌尺码问题修复后明确没有该款数值，要求产品尺码表；没有编造精确胸围。模型改写的工具参数与原问题之间的完整约束继承仍需继续加强。
- 真丝、羽绒的当前知识缺口继续明确返回未找到，没有把候选补充计划当成已发布知识。
- 税务、租赁问题的模型回复能说明没有知识依据；此前仍被服务附加 4 条、8 条检索来源（含重复），修复后均没有误挂来源。提示也要求不补未经检索支持的外部规定。

此处由 Codex 对保留的文本进行有限审读，未给出总体“回答准确率”或“引用支持率”。显式 URL 白名单只能约束链接身份，不能证明引用语义支持某句话；未来仍需独立人工逐句标注及对抗样本。

## 远端 CI 后续修复

RAG 版本在本机通过 526 项测试，但[首轮远端 Windows CI](https://github.com/yinzuosheng741-wq/travel-wardrobe-assistant/actions/runs/41179278647) 的结果是 525 项通过、1 项失败。失败来自既有长消息对话窗口测试：固定 50 毫秒滚动发生在布局最终尺寸确定之前，后续范围变化使窗口停在顶部。

修复为随滚动范围变化保持底部跟随；用户主动向上翻阅后停止跟随。新增一项无固定等待时间的回归，验证迟到的布局变化及用户翻阅行为，未删除或放宽原断言。

此后只修改桌面对话视图与对应 UI 测试，RAG 代码、题集、语料、模型提示和模型配置均保持测评时版本。检索原始报告仍绑定 RAG 版本指纹，最终发布清单同时保留 RAG 测评版本与桌面后续验证版本，不为 UI 修复重复付费接口测量。

桌面后续修复完成后，本机完整验证为 **527 项测试通过**，原历史质量门槛通过；最终发布清单保留首次 CI 失败及后续修复的区分。
