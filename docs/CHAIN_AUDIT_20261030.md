# 请求链检查记录

检查范围：桌面会话入口、确定性路由和 LangGraph、模型上下文与工具权限、Skill、RAG 索引与召回、回复及配置的外部服务。记录不包含密钥、私人照片、衣橱内容或完整请求。

## 请求链

1. `AgentService.chat` 建立单次请求策略，根据当前问题识别允许的工具；部分确定性请求直接走受限工具，其他请求进入 LangGraph。
2. LangGraph 在有限的模型和工具调用次数内编排；模型只收到系统规则、当前用户数据和有限历史，工具执行器再次检查工具许可与会话身份。衣橱写操作生成预览，仍需用户确认。
3. 知识 Skill 对当前会话资料与已审核内置记录执行关键词和可选向量检索，应用有限的材质与主题约束，检索为空时最多改写一次。来源格式和范围检查不等于语义事实核验。
4. 检索结果交给工具或模型组装回复；无模型路径直接展示首条知识摘要及其适用限制。实际模型回复是否被来源完整支持，当前没有自动蕴含验证。

## 本次修复

- 按向量服务地址和模型隔离向量集合，避免同名模型跨服务复用旧索引；向量索引同步失败后允许重新尝试。向量调用使用独立的有界执行容量，超时后的线程仍需等实际调用结束才能释放。
- 显式传递 DashScope 向量模型名及所配置密钥；复用应用上下文时，服务地址、凭据和相关设置变化会重建相应连接。凭据指纹只用于进程内缓存比较，不写日志。
- 无模型知识回复仅标注实际展示的首条证据，避免把其他召回结果误当成回复来源。
- 过滤天气接口中的无效温度、湿度和未知天气代码，避免异常值进入搭配规则。
- 旅行缺少天数时先追问，支持常见中文数字；用户后续补充天数时可使用当前会话已记录的目的地。

## 在线检查

使用个人客户端已有配置，未打印凭据；文本、视觉及 Embedding 基础连接通过。使用公开示例城市验证天气查询通过；默认城市为空且 IP 定位关闭，因而默认天气查询返回缺少城市，未开启定位。

真实模型完成了一次工具请求、接收合成天气结果并回复；真实视觉网关使用程序生成的衣服图完成结构化识别；真实 Embedding 使用一条公开知识完成临时索引与混合检索。上述检查是小样本连通及协议验证，不是模型准确率测试，也没有上传个人衣物照片。

## 仍需注意

- 固定离线 60 条检索评测的 Recall@5 基线为 0.225；题集中一些目标条目尚未发布。它不代表在线模型的实际准确率。
- 旅行目的地与天数的提取仍是有限规则，并非完整的自然语言理解；复杂行程应核对回复中的目的地和天数。
- 已知的超时保护不能强制中止同步网络线程；绑定到工具调用的容量有限，但模型 SDK 自身和进程退出仍受其超时行为影响。
- 天气结果是实时数据，示例城市成功不能保证未来网络、额度和其他城市均可用；API 能连通也不保证生成内容正确。
